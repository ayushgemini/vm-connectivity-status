What this covers

The vending machine's firmware now supports going online over either Wi-Fi or 4G LTE (SIMCom A7672S modem), with a self-serve first-time setup flow and a physical field-reset button. This note covers what's built, how an installer sets a machine up, proof it works, the one open hardware limitation, and who owns what's left.

What's implemented

All of the below is in firmware today and has been exercised end-to-end against the backend (auth, inventory, order creation) over both Wi-Fi and cellular.

Dual connectivity — Wi-Fi or Cellular

Each machine is provisioned to use one or the other. Every backend call (login, inventory, order, payment, vend, fulfil) works identically regardless of which one is active.

Hotspot-based first-time setup

No app, no cable. A new machine broadcasts its own Wi-Fi network for an installer's phone to join, then walks through the choices below.

Live connection test before saving

Whatever the installer enters, the firmware actually connects before committing it — a wrong password or APN gets caught on the spot, not after driving away.

Steady cellular sessions

The modem reuses a healthy LTE data session instead of tearing it down between requests, and only reconnects when it genuinely needs to — no unnecessary drops.

Setup flow, as an installer sees it

Runs automatically on a brand-new machine, or any time it's been reset (see below).

Join the hotspot

Machine broadcasts its own network.

SNVM-XXXXXX

Portal opens

Auto-pops on most phones, or open manually.

192.168.4.1

Choose Wi-Fi or SIM

Wi-Fi: pick from a live scan of nearby networks, sorted by signal, locked ones marked. SIM: enter the APN.

Set passcode & connect

Installer sets the machine passcode; firmware tests the connection live, saves only on success, reboots.

Field reset button

For when a machine needs to move sites, switch from Wi-Fi to SIM, or just got its passcode wrong the first time — no laptop or reflash needed.

GPIO8

Hold for 3 seconds — screen shows "Hold to Reset...", then "Resetting..." once it takes.

Wipes the saved Wi-Fi/SIM/passcode and drops the machine straight back into the setup flow above.

Ignored while the motor is mid-dispense, so a reset can never leave the relay in an unknown state.

⚠ Open limitation: antenna

After the hardware team's antenna change, cellular signal is noticeably better than before, and auth / inventory / order-creation calls now succeed reliably in bench testing.

It's still not strong or consistent enough to ship to production. This is a hardware limitation, not a firmware one — the connectivity and session-handling logic above is already built to recover from drops; the current antenna just isn't giving it a strong enough signal to hold onto in real deployment conditions.

Fix is on the hardware side: swap in the larger antenna used on our production machines.
